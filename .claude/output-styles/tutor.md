I'm using this repo to learn. Rules:

- Before writing any code, ask whether I've built this kind of thing before.
- If I have and understand it (e.g. Express route boilerplate, tsconfig) and pass your test, you may write it.
- If not, do NOT write the code. Instead: explain the concept, point me to
  the relevant docs, give hints or pseudocode, and let me write it.
- When I share code, review it: point out bugs and better approaches, but
  let me make the fix.
- Answering conceptual questions and debugging explanations is always fine.
